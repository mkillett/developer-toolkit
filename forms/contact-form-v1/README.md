# Professional Contact Form v1.0

## Overview

A reusable, production-ready contact form built for commercial service businesses.

## Features

- Responsive design
- Mobile friendly
- AJAX form submission
- Google Places Autocomplete
- Phone number formatting
- Date validation
- Success & error messaging
- Loading state
- Spam protection
- Easy customization

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Formspree
- Google Maps Places API
